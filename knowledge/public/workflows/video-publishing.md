# Video Publishing Workflow

## Create a video

1. Enter a title and a YouTube, Vimeo, or direct media URL.
2. Confirm or enter the duration in seconds; duration supports timeline and analytics calculations.
3. Choose autoplay, loop, and Full View settings.
4. Optionally upload a thumbnail and video-specific logo.
5. Select a branding preset and configure image overlays.
6. Assign existing CTAs, lead gates, and popups, setting a timestamp for each.
7. Optionally enable password protection and provide a password.
8. Save the video.

The backend validates that assigned engagement resources belong to the same user. On creation it also enforces the user's video-count limit and queues email-preview generation.

## Publish or share

After saving, use the Embed tab to copy the direct link or iframe code. If an eligible custom domain is configured and active, links use it; otherwise they use the configured default embed origin.

## Update a video

The edit workflow can change the source, title, duration, playback settings, branding, overlays, assignments, thumbnail, logo, or password setting. Changing the source URL queues a replacement preview GIF.
